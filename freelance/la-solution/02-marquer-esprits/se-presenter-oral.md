**SE PRÉSENTER À L’ORAL : LES 4 ÉTAPES INDISPENSABLES**

**\#1 : Que fais-tu dans la vie ?** 

Chaque rencontre peut vous apporter des opportunités. 

Si vous captez l’attention de votre interlocuteur, il voudra en savoir plus sur vous. 

***“J’aide X à faire Y”.***

**\#2 Le schéma actantiel : positionnez votre client comme un héro** 

Votre client : le héros  
Vous : l’Adjuvant   
Obstacle : ce qui bloque le client  
Quête : Objectif du client   
Résultat : Gain du client

**\#3 Creuser dans l’émotion**
