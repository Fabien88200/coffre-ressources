**GÉRER UNE CRISE : LES BONNES PRATIQUES**

**Qu’est-ce qu’on peut qualifier de crise ?** 

Certains problèmes sont inévitables : 

* Problème de deadline  
* Résultat non attendu   
* Problème dans l’équipe

Un problème non traité devient rapidement **une crise.**

→ communiquer rapidement, clairement et montrer que vous faites le nécessaire.

**Prenez du recul**

Vous serez probablement dans un état émotionnel instable.

Essayez de **comprendre** vos interlocuteurs : 

*D’où vient la crise ?* 

**Rassurer** le client.

**Crise \#1 : Problème de deadline**

Expliciter toujours une **deadline précise** pour le projet.

**Si une crise surgit** : proposer une nouvelle deadline, faites passer le projet en priorité, tenez le client informé dans les heures qui suivent le problème.

**Crise \#2 : Résultat non attendu** 

Ex : peu de ventes après une campagne FB.

**En amont : expliquer les attentes et les risques.**

**Si une crise surgit** : analyser la situation, comprendre ce qui n’a pas marché et comment faire mieux.  
Proposer une solution alternative si légitime.
