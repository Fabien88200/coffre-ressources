**GÉRER LES DEVIS, FACTURES ET RELANCES**

**Qu'est-ce qu’un devis ?** 

**Le devis est un contrat qui définit les attentes, le projet, les tarifs et les délais.** 

L’objectif est de **minimiser les conflits futurs** en éliminant au maximum les ambiguïtés et les zones d’interprétation. 

Vous devez TOUJOURS faire signer le devis avant de commencer votre prestation.

**Pas de signature, pas de travail.** 

Aucun recours n’est possible si le devis n’est pas signé. 

**Que doit contenir le devis ?** 

Les coordonnées du client.  
Vos coordonnées.   
Livrables et leurs prix.   
Durée de validité du devis.  
Termes de paiement (à réception de facture, 30 jours, 90 jours) et montant de l'acompte si il y a.   
CGV si applicables.

**Comment gérer les devis ?** 

Erreur courante : les faire sous même sous Word. 

Utiliser un outil de facturation. 

**Quand se passer d’un devis ?** 

**Uniquement** si vous avez un contrat qui remplace le devis avec les mentions précises de revenus. 

Le contrat doit être signé par **les deux parties.** 

**Quand relancer un devis ?** 

Relance à J+7 et J+14.

Battre le fer tant qu’il est chaud : plus vous attendez, moins vous aurez de chance de signer. 

**Qu’est-ce qu’une facture ?** 

La facture est un document que vous envoyez à votre client pour lui demander de vous payer. 

Elle est envoyée dans **3 situations** : 

- si vous demandez un acompte  
- à la fin d’une mission  
- à chaque échéance de paiement   
  


**Que doit comporter une facture ?** 

Mêmes informations que le devis.

Échéance de paiement (en général 30J).
