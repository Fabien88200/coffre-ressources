# Search Engine Marketing

Module du bachelor Chef de Projet Digital.

Le module couvre en réalité trois disciplines : SEO (référencement naturel), SEA (référencement payant) et SMO (réseaux sociaux).

## Contenu

### Cours théoriques

- `cours-seo.md` — Search Engine Optimization (piliers, arborescence, balises, contenu, netlinking, EEAT, KPIs).
- `cours-sea.md` — Search Engine Advertising (Google Ads, formats, régies, enchères, CPA/CPC/ROAS, remarketing).
- `cours-smo.md` — Social Media Optimization (choix des plateformes, calendrier éditorial, loi de Pareto, KPIs par objectif).

### Applications

- `strategie-rab2-frites.md` — Cas d'application personnel : stratégie SEM complète (SEO + SEA + SMO) pour le restaurant fictif RAB'2 Frites, avec personas, arborescence, mots-clés, KPIs et objectifs SMART.
